## 📌 ১. এক নজরে DocBD (Executive Overview)

DocBD হলো বাংলাদেশের প্রাইভেট ডাক্তার চেম্বার ও ডায়াগনস্টিক হাসপাতালের বহির্বিভাগের (OPD) জন্য বিশেষভাবে তৈরি একটি **রিয়েল-টাইম লাইভ সিরিয়াল ও পেশেন্ট এনগেজমেন্ট প্ল্যাটফর্ম**। 

বাংলাদেশের লাখ লাখ রোগী ডাক্তার দেখাতে এসে ঘণ্টার পর ঘণ্টা অস্বস্তিকর ওয়েটিং রুমে বসে থাকেন, কারণ সিরিয়াল খাতার কোনো ডিজিটাল বা লাইভ ট্র্যাকিং ব্যবস্থা নেই। DocBD ডাক্তারের বিশ্বস্ত সহকারী (কম্পাউন্ডার)-কে ক্ষমতাচ্যুত না করে বরং তার হাতে একটি **সহজ ডিজিটাল খাতা (ট্যাবলেট অ্যাপ)** তুলে দেয় — যার ফলে ওয়াক-ইন, টেলিফোন ও অনলাইন সব বুকিং এক সাথে মিলে যায় এবং রোগীরা নিজ ফোনে লাইভ দেখতে পান ভেতরে কত নম্বর সিরিয়াল চলছে।

### 💎 ৩টি অটুট নীতি (Unbreakable Core Principles):
1. **চেম্বার-ফার্স্ট (Chamber-First, Not Video-Call Broker):** মূল ফোকাস সরাসরি চেম্বারে ডাক্তারের মুখোমুখি শারীরিক চেকআপ। টেলিমেডিসিন শুধুমাত্র ফলো-আপের জন্য।
2. **"ডাক্তারের রোগী ডাক্তারেরই" (Strict Non-Poaching Rule):** HotDoc-এর মতো বিতর্ক এড়াতে DocBD কোনো ডাক্তারের রোগীকে অন্য ডাক্তারের কাছে যাওয়ার বিজ্ঞাপন দেখায় না। ডাক্তারের নিজস্ব রোগীবেস সম্পূর্ণ সুরক্ষিত।
3. **আল্ট্রা-অ্যাক্সেসিবল (Bangla-First & Easy Mode):** গ্রামীণ ও বয়স্ক রোগীদের জন্য ২০% বড় ফন্ট ও ভয়েস নির্দেশিকা সহ 'সহজ মোড'। স্মার্টফোন ছাড়া রোগীদের জন্য স্বয়ংক্রিয় বাংলা SMS রিমাইন্ডার এবং চেম্বারে নগদ (Cash-at-Chamber) ডিফল্ট পেমেন্ট।

## 🖥️ ২. সংযুক্ত ৫টি স্ক্রিন ও মডিউল (Integrated Ecosystem)

| ভিউ / স্ক্রিন | ডিভাইস / টার্গেট | মূল কাজ ও ফিচার |
|---|---|---|
| **📱 রোগীর মোবাইল অ্যাপ (PWA)** | রোগীর স্মার্টফোন / ব্রাউজার | জিপিএস নিকটস্থ ডাক্তার ও হাসপাতাল খোঁজা, স্লট বুকিং (ফ্রি), লাইভ টিকিট কাউন্টডাউন ("ভেতরে ৫, আপনার ১২"), ২০০মি. জিওফেন্স স্ব-উপস্থিতি ("✓ আমি পৌঁছেছি"), ডিজিটাল প্রেসক্রিপশন ভল্ট ও ওষুধের অ্যালার্ম। |
| **📋 কম্পাউন্ডার ডিজিটাল খাতা** | ক্লিনিক কাউন্টার ট্যাবলেট | রিয়েল-টাইম একক খাতা। ১-ক্লিকে বড় অ্যাকশন বাটন (`পরবর্তী রোগী ডাকুন`, `ভিজিট সম্পন্ন`, `অনুপস্থিত/No-show`, `হোল্ড`), ওয়াক-ইন/টেলিফোন এন্ট্রি, ডাক্তার ট্রাফিকে আটকালে তাৎক্ষণিক বাল্ক SMS ব্রডকাস্ট। |
| **👨‍⚕️ ডাক্তার ওপিডি পোর্টাল** | ডাক্তারের ডেস্কটপ ল্যাপটপ | ৪৫-সেকেন্ড কুইক ই-প্রেসক্রিপশন (স্কয়ার, বেক্সিমকো, ইনসেপ্টা ড্রপডাউন), রোগীর ভাইটাল ও পূর্বের হিস্ট্রি, হাসপাতালে টেস্ট বুকিং লিঙ্ক, ফলো-আপ অটো SMS রিকল শিডিউলার। |
| **🏢 হাসপাতাল সেন্ট্রাল ড্যাশবোর্ড** | অ্যাডমিন / এমডি অফিস | ওপিডি সেন্ট্রাল মনিটরিং, ঘণ্টায় ঘণ্টায় ফুটফল চার্ট (Footfall Analysis), ডাক্তার রোস্টার, সেন্ট্রাল নোটিশ ব্রডকাস্ট, নিজস্ব ওয়েবসাইট ও ফেসবুকে বুকিং উইজেট এমবেড কোড। |
| **📺 ওয়েটিং রুম টিভি ডিসপ্লে** | ওয়েটিং রুম স্মার্ট টিভি | ফুলস্ক্রিন ডিজিটাল বোর্ড, লাইভ ক্লক, বর্তমানে ভেতরে ডাকা সিরিয়াল নম্বর, পরবর্তী অপেক্ষমাণ ৫ জন রোগীর তালিকা ও স্পিকার বিপ নোটিফিকেশন। |

## ⚡ ৩. লোকাল পরিবেশে চালানো (Quick Start Guide)

DocBD প্রোটোটাইপটি **জিরো এক্সটারনাল ডিপেন্ডেন্সি (Zero-Build Vanilla ES6)** আর্কিটেকচারে তৈরি। আপনি সরাসরি ব্রাউজার বা যেকোনো সাধারণ HTTP সার্ভার দিয়ে এটি তাৎক্ষণিক রান করতে পারবেন।

### অপশন ক: সরাসরি বিল্ট-ইন পাইথন সার্ভার (সর্বোত্তম ও দ্রুততম)
```powershell
# প্রজেক্ট ডিরেক্টরিতে যান
cd c:\Innovation\DocBD

# লোকাল HTTP সার্ভার চালু করুন (পোর্ট 8080)
python -m http.server 8080

# আপনার ব্রাউজারে খুলুন:
# http://localhost:8080/index.html
```

### অপশন খ: নোড / ফাস্টাইফাই ব্যাকএন্ড API সার্ভার সহ চালানো
```powershell
cd c:\Innovation\DocBD\server

# ডিপেন্ডেন্সি ইন্সটল করুন
npm install

# ব্যাকএন্ড API ও লাইভ WebSocket সার্ভার রান করুন (পোর্ট 5000)
npm run dev
```

## 🎯 ৫. ডেমো টেস্ট দৃশ্যপট (Investor & Partner Walkthrough)

প্রোটোটাইপটি ওপেন করে নিচের টেস্ট ফ্লো যাচাই করুন:
1. **লাইভ সিঙ্ক ট্যাব (🔄 লাইভ সিঙ্ক):** রোগীর মোবাইল ও কম্পাউন্ডারের খাতা পাশাপাশি প্রদর্শিত হবে।
2. **রোগী অ্যাপে বুকিং ও উপস্থিতি:** 
   * ধানমন্ডি পপুলার ডায়াগনস্টিকে ডা. রফিকুল ইসলামের সিরিয়াল বুক করুন।
   * "✓ আমি পৌঁছেছি" চাপুন — কম্পাউন্ডারের স্ক্রিনে তাৎক্ষণিক "ক্লিনিকে উপস্থিত (Check-in)" স্ট্যাটাস সবুজ হয়ে যাবে।
3. **কম্পাউন্ডার কন্ট্রোল:** 
   * `পরবর্তী রোগী ডাকুন` চাপুন — সাথে সাথে একটি অডিও চিম বাজবে এবং টিভি ডিসপ্লে ও রোগীর স্ক্রিনে বর্তমান টোকেন আপডেট হবে।
   * `ডাক্তার বিলম্ব SMS` চাপুন — সকল অপেক্ষমাণ রোগীর ফোনে স্বয়ংক্রিয় বাংলা বিলম্ব SMS চলে যাবে।
4. **ডাক্তার পোর্টাল (👨‍⚕️ ডাক্তার পোর্টাল):**
   * ড্রপডাউন থেকে ওষুধ (Bizoran, Napa Extra, Seclo) সিলেক্ট করে টেস্ট লিখে `ডিজিটাল প্রেসক্রিপশন ইস্যু করুন` চাপুন।
   * প্রেসক্রিপশনটি সরাসরি রোগীর ডিজিটাল ভল্টে যুক্ত হবে এবং দৈনিক ওষুধের অ্যালার্ম তৈরি হবে।
5. **সহজ মোড ও জরুরি হেল্পলাইন:**
   * হেডার থেকে `👓 সহজ মোড` চাপুন — ফন্ট বড় হবে ও বৈসাদৃশ্য বাড়বে।
   * `🚨 জরুরি (999)` চেপে জাতীয় অ্যাম্বুলেন্স ও স্বাস্থ্য বাতায়ন হেল্পলাইনে কল সিমুলেট করুন।
